# مدیریت پروژه و تسک تیم رسا

یک وب‌اپ فارسی و راست‌چین برای تعریف پروژه‌ها و تسک‌ها، پیگیری وضعیت، انتساب افراد و دیدن همه چیز در یک تقویم شمسی. روی لپ‌تاپ و موبایل کار می‌کند و روی گوشی مثل یک اپ نصب می‌شود.

همه چیز روی گیت‌هاب است و هیچ سرویس دیگری لازم نیست:

- **خود برنامه** روی GitHub Pages از همین مخزن منتشر می‌شود (`https://<سازمان>.github.io/rasa-task-tracker/`).
- **داده‌ها** در یک فایل JSON در مخزن خصوصی `rasa-task-data` ذخیره می‌شوند. هر تغییر یک commit است، پس تاریخچه کامل تغییرات همیشه هست.
- **ورود**: هر عضو تیم یک بار با کلید دسترسی (fine-grained token) خودش وارد می‌شود. کلید فقط روی همان دستگاه ذخیره می‌شود.

راهنمای راه‌اندازی و اضافه کردن اعضای تیم: [docs/SETUP.md](docs/SETUP.md)

## امکانات

- پروژه‌ها با وضعیت، اولویت، تاریخ شروع و پایان، اعضا، رنگ و درصد پیشرفت (بر اساس تسک‌های انجام‌شده)
- تسک‌ها، مستقل یا زیرمجموعه پروژه، با چند مسئول، چک‌لیست مراحل، تاریخ شروع و مهلت
- نمای فهرست و بورد وضعیت، فیلتر بر اساس وضعیت، فرد، پروژه و مهلت، و نشان «عقب‌افتاده»
- صفحه پروفایل هر فرد با پروژه‌ها، تسک‌ها و رویدادهایش
- تقویم ماهانه شمسی (شنبه تا جمعه) با شروع و پایان پروژه‌ها و تسک‌ها و رویدادهای دلخواه
- همگام‌سازی خودکار هر ۳۰ ثانیه؛ اگر دو نفر هم‌زمان ذخیره کنند، تغییر هیچ‌کدام گم نمی‌شود
- نسخه نمایشی بدون ورود، برای دیدن برنامه قبل از راه‌اندازی

## برای توسعه‌دهنده

```bash
npm install
npm run dev        # http://localhost:5173 (دکمه «نسخه نمایشی» بدون نیاز به کلید کار می‌کند)
npm test           # آزمون‌های تاریخ شمسی و همگام‌سازی
npm run build
```

ساختار:

```
src/lib/github.ts     خواندن و نوشتن فایل داده با GitHub REST API
src/data/sync.ts      صف تغییرات، ذخیره، و حل تداخل ذخیره‌های هم‌زمان
src/data/backend.ts   ذخیره در گیت‌هاب یا (در حالت نمایشی) در مرورگر
src/lib/date.ts       تاریخ شمسی
src/pages/            صفحه‌ها
src/components/       اجزای رابط کاربری و فرم‌ها
```

هر تغییر به شکل یک تابع کوچک ثبت می‌شود و روی آخرین نسخه ذخیره‌شده اعمال می‌شود. اگر هم‌تیمی زودتر ذخیره کرده باشد، گیت‌هاب تداخل را اعلام می‌کند، برنامه نسخه تازه را می‌گیرد و همان تغییر را دوباره روی آن اعمال می‌کند.

انتشار: با هر push به شاخه `main`، گردش کار `.github/workflows/deploy.yml` آزمون‌ها را اجرا می‌کند و سایت را روی GitHub Pages منتشر می‌کند. مخزن داده‌ها به طور پیش‌فرض `<همان سازمان>/rasa-task-data` است و با متغیر `DATA_REPO` در تنظیمات مخزن قابل تغییر است.
